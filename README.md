# Carta de aniversario #8

Web sencilla (HTML + CSS + JavaScript, sin dependencias) para celebrar nuestro octavo aniversario.

## Personalizar

1. `script.js` → bloque `CONFIG` al inicio: nombre cariñoso, firma y fecha del aniversario.
2. `index.html` → el texto de la carta (`<article class="paper">`) y los 8 recuerdos de la línea de tiempo.
3. `style.css` → colores en `:root` si quieres otra paleta.

Para probarla en local, abre `index.html` en el navegador.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub y sube estos archivos.
2. En el repo: **Settings → Pages → Build and deployment**.
3. Source: **Deploy from a branch**, rama `main`, carpeta `/ (root)` → **Save**.
4. En ~1 minuto estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

> Tip: si no quieres que la carta sea pública, usa un nombre de repo poco obvio, ya que
> GitHub Pages es accesible para quien tenga el enlace.
